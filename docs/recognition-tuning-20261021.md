# ResNet18 类别平衡与微调实验

日期：2026-10-21。目标是检验类别加权和只微调 ResNet18 `layer4` 是否能改善四类红树识别。实验不修改正式 `backend/recognition/artifacts/`。

## 数据与划分

沿用前次实验的 238 张训练图和固定 56 张留出图（原数据按摄影者留出 31 张，中国观察组留出 25 张）。固定留出图片和观察组 ID 与 `data/recognition-china-experiment-20261021/comparison.json` 一致。

238 张训练图按类分别为木榄 30、桐花树 29、秋茄 92、白骨壤 87。内部开发集按物种与摄影者分组，选择各类约 20% 的完整摄影者组；训练 191 张、开发 47 张，无摄影者组交叉。开发集分别为木榄 6、桐花树 6、秋茄 18、白骨壤 17 张。中国组秋茄照片高度集中于一名摄影者，因此摄影者独立切分对结果影响很大。

## 开发集比较

| 训练方案 | 开发集正确/总数 | 准确率 |
| --- | ---: | ---: |
| 冻结主干，普通分类头 | 29/47 | 61.70% |
| 冻结主干，逆频率类别权重 | 22/47 | 46.81% |
| 只微调 `layer4`，无类别权重 | 32/47 | 68.09% |
| 只微调 `layer4`，逆频率类别权重 | 32/47 | 68.09% |

按开发集准确率并列时按固定顺序选择普通 `layer4` 微调，以全部 238 张训练图重训并导出 ONNX。PyTorch 与 ONNX 的最大 logit 差为 `2.86e-6`。

## 固定留出集结果与决定

| 候选 | 固定留出集正确/总数 | 准确率 |
| --- | ---: | ---: |
| 前次冻结主干候选 | 38/56 | 67.86% |
| 本次普通 `layer4` 微调 | 37/56 | 66.07% |

本次训练没有提高固定留出集表现，低于 75% 门槛。候选仅保存在本机 `data/recognition-tuning-20261021/model.onnx`；不替换正式服务模型。`readyForDemo` 继续为 `false`，自动识别失败时继续手动选择物种。

这是探索性结论：这 56 张留出图在此前实验中已用于比较，且中国观察组与训练组存在摄影者重合，不能再称为全新盲测，更不能代表湛江现场准确率。内部开发集只有 47 张，其中木榄和桐花树各 6 张，单次结果波动较大。继续针对这批图片调参，容易对验证集过拟合。

## 下一步采集与验收

优先在湛江补木榄、桐花树的不同地点和不同个体；秋茄、白骨壤也应补当地照片，以覆盖现场手机、天气和背景。每种至少 3 个地点，每处 4～6 棵不同个体，每棵拍叶、根/树干、整株、繁殖结构及不同光照视角，每棵树的照片作为一个组。保留原图、物种人工复核结果、地点、个体编号、摄影者和拍摄日期。先锁定独立地点和个体作最终验收，不参与训练或调参；未知种、模糊图也需单独测试 fallback。不要把一棵树的连拍拆到训练和验收两侧。

复现命令：

```powershell
.\.venv\Scripts\python.exe tools\tune_resnet18.py
```

数值详情见 `data/recognition-tuning-20261021/comparison.json`。模型文件被 Git 忽略，重跑脚本可以生成。
