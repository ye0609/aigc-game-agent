## D-002：先保留可替换识别基线

- 日期：2026-10-18
- 状态：已确认
- 决定：第 2 周先使用 `backend/recognition/` 的可复现基线跑通数据检查、训练、评估和推理；真实样本到齐后再根据验证集和现场照片决定是否换迁移学习模型。
- 原因：没有训练图片时无法诚实报告识别率，但可以先把目录、稳定 ID、评估口径和接口输出固定下来。
- 兜底：当置信度不足或现场测试不稳定时，前端使用“手动选物种 + GPS 点位卡片”。

## D-003：更正木榄的物种 ID

- 日期：2026-10-18
- 状态：已确认
- 决定：将木榄的示例 ID 从 `mangrove-rhizophora-apiculata` 改为 `mangrove-bruguiera-gymnorrhiza`。
