# 地点数据来源与现场校准

更新时间：2026-10-18（晚）

## 坐标系

`data/sites.json` 统一保存 **WGS-84**。三个站点的中心、栈道点和观鸟点由 C 于 2026-10-18 提供，属于 **WGS-84 参考坐标，尚未现场实测**。

A 使用高德/腾讯地图时，需要先用标准 WGS-84 → GCJ-02 公式转换，再打点/画线；不要把 WGS-84 值直接传给高德，否则会偏 300–600 米。OSM、GPS 设备可直接使用 WGS-84。

> 变更说明：上一版曾把 C 给的高德点按 GCJ-02 入库，但 C 随后提供了一套完整的 WGS-84 站点 + 栈道 + 观鸟点数据；两套点在特呈岛和金牛岛相差约 1 km，不能混用。本版以 C 最新的 WGS-84 参考坐标为准，站点中心也改回 WGS-84。

## 这版不是现场实测

这些点是 C 提供的 WGS-84 参考坐标，用来先把地图点位、栈道线和观鸟点渲染出来；它们还不等于现场控制点。`data/test_sites_data.py` 会检查每条描述里保留“参考坐标”和“尚未现场实测”，防止把参考数据当成实测成果。

在完成现场校准前：

- 前端可以画站点、栈道线和观鸟点，但应标注“参考坐标，待现场校准”；
- 不要把它当作盲导航或救援坐标；
- 特呈岛有东、西两条栈道分支，当前 `route` 走主线到东分支终点，西分支观景台放在 `birdWatchingShelters` 里；现场采集时可以补第二条分支。

## 现场校准清单

每个站点至少复核以下点，统一用 WGS-84、手机 GPS 连续读 3 次取平均，记录精度：

1. 停车场/入口/门楼
2. 栈道起点
3. 栈道每个转折点或分叉点（每 100–200 米一个）
4. 栈道终点/码头
5. 每个观鸟亭、观鸟台、瞭望塔
6. 卫生间/出口（可选，但建议）

同时拍一张带时间戳的现场照片，记录潮位和天气。回到仓库后：

1. 用实测值替换 `data/sites.json` 里对应的点；
2. 把 `description` 里的“参考坐标，尚未现场实测”改成“已完成现场校准”，写日期；
3. 运行：

   ```bash
   python data/test_sites_data.py -v
   ```

4. 高德/腾讯地图在运行时把 WGS-84 转 GCJ-02；不要改仓库里的 WGS-84 基准。
