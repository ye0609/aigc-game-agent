# 红树林知识库

本目录是 `/api/knowledge/ask` 的本地检索来源，当前为“RAG-lite”演示知识库，不是完整百科。

## 文档

- `mangrove-species.md`：四种重点红树及识别提醒
- `ecosystem.md`：防风浪、育幼场、生物多样性
- `blue-carbon.md`：蓝碳概念、红树林碳库、引用口径
- `birds.md`：黑脸琵鹭、白鹭、勺嘴鹬与观鸟礼仪
- `visiting.md`：三个点位、路线、潮汐与安全

## 回答规则

- 先按问题意图命中对应文档（物种/生态/蓝碳/鸟类/点位/安全）。
- 未命中时做关键词检索；检索不到可靠内容时明确回答“当前知识库没有收录”，不编造答案。
- 回答末尾返回实际来源文件路径，前端展示“来源”。

## 注意

- 知识库里的保护等级、数量和分布以保护区官方名录、现场公告为准。
- 蓝碳数字区分“碳储量”“年固碳速率”“碳汇交易”，不把示例数字当权威统计。
- 这里的内容用于研学演示，不替代正式科研引用。
