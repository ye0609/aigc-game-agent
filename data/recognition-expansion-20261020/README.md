# 四类红树候选扩充照片（2026-10-20）

本目录登记了 90 张**相对于原 147 张全新**的 iNaturalist 照片。每张照片来自不同观察记录，并在 `sources.csv` 中记录观察页、摄影者、照片许可证、原图地址和 SHA-256；`groups.csv` 记录观察分组。四类分别新增桐花树 23、白骨壤 23、木榄 23、秋茄 21 张。照片许可证为 CC BY 71、CC0 13、CC BY-SA 6。收集时仅接受研究级观察和该照片明确标注的上述许可证。

照片文件在本机目录中，因大小和来源管理而被 Git 忽略。其他机器可按来源清单恢复，并逐张校验 SHA-256：

```bash
python tools/collect_training_images.py --root data/recognition-expansion-20261020 --restore
```

缩略图人工筛查排除了 3 张主体难以辨认的照片（观察 ID `364570210`、`213354782`、`197943329`）。候选集可见叶片近景、花和胚轴、整株、树干与泥滩背景，以及不同光照和拍摄距离；例如白骨壤 `IMG_0044.jpg` 为叶片近景、`IMG_0051.jpg` 为树干环境，木榄 `IMG_0043.jpg` 为花、`IMG_0055.jpg` 为根部环境，秋茄 `IMG_0019.jpg` 为胚轴、`IMG_0058.jpg` 为群落远景。观察级物种标签及缩略图检查不能代替植物专家逐张复核，也不能证明这些图片来自湛江现场。

原有训练集和模型保持不变。用固定的、按摄影者隔离的原数据验证集，对比扩充前后的实验：

```bash
python tools/evaluate_photo_expansion.py --extra-root data/recognition-expansion-20261020
```

实验中的 90 张候选照片有 67 张进入扩充训练集：14 张来自留出集摄影者，9 张超过每位摄影者最多 7 张的上限。两次训练均在同一 29 张照片上验证，结果从 `20/29 = 0.6897` 到 `21/29 = 0.7241`。未达到 `0.75` 门槛，因此不部署候选模型；仍使用手动选择兜底。详细方法见 `docs/recognition-expansion-20261020.md`。

这些照片只用于识别研发。若在页面、答辩材料或公开数据集中使用，请按 `sources.csv` 的每张照片许可证和摄影者信息处理署名及再利用要求。
